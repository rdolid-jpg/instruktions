Повний практичний посібник: типи повідомлень, налаштування полів бек-офісу, системні Deep Links, статистика доставлення та готові шаблони.

1. Базова концепція: Що таке Inbox та як він влаштований

▲

Inbox (Центр сповіщень) — це внутрішній поштовий канал бренду. На відміну від спливаючих Pop-up чи зовнішніх Push/Email, сповіщення Inbox зберігаються у віджеті дзвоника гравця на сайті та доступні для повторного перегляду.

Simple Inbox vs Rich Body Inbox

Параметр Simple Inbox (Простий) Rich Body Inbox (Кастомний)
Візуальний вигляд Тільки стандартна плашка: іконка, короткий заголовок та прев'ю-текст. Повноцінний гарний банер із кастомним HTML-оформленням у розгорнутому вікні.
Поведінка кліку Одразу перенаправляє гравця за посиланням або Deep Link (поле Deep link or URL). Клік відкриває картку сповіщення всередині віджета з детальним HTML-вмістом та CTA-кнопками.
Action у Smartico Вказується конкретний URL або лінк (наприклад, dp:go&url=/deposit). ОБОВ'ЯЗКОВО обирається dp:inbox (інакше віджет платформи відкине HTML-код та кнопки).
Кнопки дії (CTA) Не підтримуються (клік по всій плашці). До 2 нативних інтерактивних кнопок (Primary та Secondary) із персональними посиланнями.
💡 Поведінка спливаючого прев'ю (Toast): якщо гравець онлайн на сайті в момент відправки і увімкнено опцію Show preview of the message for a short period if user is online, у кутку екрана показується невелике спливаюче сповіщення. За замовчуванням тривалість показу — 7 секунд. Якщо потрібно показувати 10 секунд, додайте у поле Extra parameters JSON: {"visibility_period_sec": 10}.

2. Налаштування полів у BackOffice Smartico

▲

Покроковий довідник із заповнення полів форми при створенні сповіщення (розділ Communications → Inbox):

Поле у BackOffice Призначення Рекомендоване значення для WhiteLabel
Name Внутрішня системна назва повідомлення для пошуку в списку. [IB] Retention_Bonus_10FS_v1
Status Статус ресурсу. Active (тільки активні ресурси надсилаються гравцям).
Message expiration period Скільки часу повідомлення живе у віджеті користувача після відправки. Рекомендовано 7–14 днів (за замовчуванням стоїть 30 днів; максимум 365).
Title Заголовок інбокс-повідомлення у списку віджета. Короткий текст до 30–40 символів (наприклад, «Daily bonus»).
Short preview for body Текст прев'ю, який гравець бачить у списку сповіщень та у спливаючому тості. До 70–80 символів. Має зацікавити розгорнути сповіщення.
Inbox message type Тип поведінки повідомлення. Rich body (HTML) для банерів або Simple для швидких переходів.
Deep link or URL Цільове посилання для відкриття. Для Rich body завжди dp:inbox. Для Simple — потрібний Deep Link.
CTA Primary Button Text Текст головної кнопки дії (жовта акцентна кнопка). Наприклад: Deposit або Activate bonus.
Deep link for Primary Button Куди переходить гравець при натисканні головної кнопки. dp:go&url=/deposit#cashbox або dp:go&url=/profile/gifts.
CTA Secondary Button Text Текст другої допоміжної кнопки (сіра кнопка). Заповнюється лише за потреби (наприклад, Deposit).
Deep link for Secondary Button Посилання для другої кнопки. Системний Deep Link (наприклад, dp:go&url=/deposit#cashbox).
Extra parameters Додаткові системні налаштування у форматі JSON. Вкажіть {"visibility_period_sec": 10} для тосту на 10 секунд.
⚠️ КРИТИЧНО ПРО ПОСИЛАННЯ: Усередині HTML-коду Rich Body НЕ МОЖНА використовувати звичайні теги <a href="...">, оскільки пісочниця iframe віджета блокує зовнішні переходи через обмеження CSP браузера. Усі кліки гравця мають відбуватися ВИКЛЮЧНО через CTA-кнопки бек-офісу!

3. Системні Deep Links та логіка статистики Inbox

▲

Формат перенаправлення (dp:go&url=)

Для переходу на сторінки проєкту використовується спеціальний внутрішній протокол Smartico: dp:go&url=. Параметр url= завжди розміщується останнім. Для відкриття в новій вкладці можна додати параметр: dp:go&target=_blank&url=....

Цільова дія гравця Значення для поля Deep Link Примітка
Каса / Депозит dp:go&url=/deposit#cashbox Відкриває модальне вікно внесення депозиту.
Бонуси / Подарунки dp:go&url=/profile/gifts Розділ активації бонусів профілю.
Розділ Місій dp:gf_missions Гейміфікація Smartico (список завдань).
Магазин балів dp:gf_store Gamification Store з призами.
Турніри dp:gf_tournaments Турнірні таблиці та активні змагання.
Колеса фортуни / Міні-ігри dp:go&url=/minigames Сторінка промо або розваг.

Як рахується статистика Inbox у звітах Smartico BI

Оскільки Inbox — це внутрішній віджет платформи без зовнішнього поштового провайдера чи мобільного оператора, статуси працюють за спеціальною схемою:

  • Sent (Надіслано): фіксується в момент спрацьовування кроку кампанії. Повідомлення миттєво записується у базу віджета користувача (незалежно від того, онлайн гравець чи офлайн).
  • Delivered (Доставлено) = Impression: технічного статусу доставки через шлюз в Inbox не існує. У звітах BI метрика Delivered прирівнюється до Impression. Для онлайн-гравців Impression зараховується в момент появи спливаючого тосту на екрані. Для офлайн-гравців повідомлення чекає у списку, і факт зараховується при вході на сайт та відкритті віджета.
  • Clicked (Клік): фіксується у системі, коли користувач натискає на одну з інтерактивних CTA-кнопок.
