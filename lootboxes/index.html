Повна інструкція: від налаштування до кастомізації скінів

📦 1. Lootbox 2.0: огляд та порівняння з Lootbox 1.0

🎯 Що таке Lootbox 2.0?

Lootbox 2.0 — це ігровий інструмент у Smartico, призначений для проведення щоденних акцій: адвент-календарів, марафонів, daily-бонусів. Гравець щодня відкриває коробку або картку та отримує приз.

Основні можливості Lootbox 2.0:

  • 2 типи макетів (Layout): Map (календар/мапа) та Cards (картки горизонтальним рядом).
  • 2 типи розкладу (Schedule): Calendar Days (конкретні дати) та Weekdays (повторювані дні тижня).
  • Контроль часового поясу (Timezone): призи згорають опівночі за часом гравця або за фіксованим часом.
  • Кастомні скіни: повна заміна візуального оформлення через Mini-games skin editor.
  • Типи призів: no prize, points, bonus, tangible (фізичні товари), spin (спроби в міні-іграх) та mission (тільки типу 'Featured Manually').
  • Prize Acknowledgment: можливість вимагати ручне підтвердження отримання призу.
  • Рандомізація: можливість призначати кілька призів на один день (гравець отримає один випадковим чином).

⚡ Lootbox 1.0 (стара версія)

Lootbox 1.0 — попередня версія, яка залишається в системі для складних кастомних сценаріїв. Її налаштування є більш трудомістким і має більше змінних параметрів.

⚠️ Коли використовувати Lootbox 1.0

Тільки коли видача призу залежить від складних умов (факт депозиту, ставки), або коли потрібно відправити Webhook, запустити іншу кампанію, додати/видалити мітки гравцю.

✅ Коли використовувати Lootbox 2.0

Для 99% випадків щоденних акцій. Налаштовується за 10-15 хвилин, не потребує участі розробників.

⚙️ 2. Покрокове налаштування Lootbox 2.0

📋 Крок 0: Підготовка

  • Підготуйте список призів: тип, назва, зображення, кількість (stock).
  • Визначте часовий пояс кампанії.
  • Підготуйте скін (набір зображень) згідно з вимогами з Розділу 4.
  • Підготуйте картинки для призів: квадратне зображення (рекомендовано 512x512)

🏗️ Крок 1: Створення гри

  • Перейдіть у Back Office → Gamification → Retention Games → Lootbox.
  • Натисніть кнопку «Create».
  • Витберіть Lootbox Weekdays або Lootbox Calendar Days в залежность від механіки.
  • У полі «Name» введіть назву. Важливо: Після збереження гри буде автоматично створено Custom Section з такою ж назвою — це потрібно для посилань.
  • У полі «Visual layout» оберіть Map (календар) або Cards (картки).

📅 Крок 2: Налаштування розкладу

  • Schedule type: оберіть Calendar Days (конкретну дату початку і кількість днів) або Weekdays (дні тижня).
  • Для Calendar Days: вкажіть Start Date та Lootbox duration, days. Система автоматично розрахує кількість днів і створить відповідну кількість призів.
  • Для Weekdays: оберіть дні тижня (Mon, Tue, Wed, Thu, Fri, Sat, Sun).
  • Timezone for days boundaries: оберіть часовий пояс цільової аудиторії. Calendar days, user time zone — призи згорають опівночі за часом гравця.

🎁 Крок 3: Налаштування призів

  • Після вибору розкладу система автоматично створила необхідну кількість днів. Перейдіть у вкладку «Prizes».
  • Для кожного дня натисніть «Edit».
  • Заповніть поля:
    • Prize type: Points, Bonus, Tangible, Spin, Mission (тільки 'Featured Manually') або No prize.
    • Prize name: назва призу (відображається гравцю).
    • Icon: завантажте квадратне зображення (рекомендовано 512x512).
    • Items in stock (current): 0 = нескінченний пул. Обов'язково увімкніть параметр 'Surcharge' для коректного обліку.
    • Winning message: оберіть або створіть повідомлення про виграш..

💡 Рандомізація (Кілька призів на день)

Ви можете додати кілька різних призів на один день (працює і для Cards, і для Map). У такому випадку гравець отримає один із цих призів, який система обере випадковим чином!

💡 Prize Acknowledgment (Ручне підтвердження)

Щоб гравець підтверджував отримання призу, у полі 'Type of Winning Message' оберіть 'Full message with acknowledge button'. Приз буде видано лише після натискання кнопки 'Claim'. Не забрані призи потраплять у вкладку 'Not Claimed Prizes', де оператор може видати їх вручну кнопкою 'Claim Manually'.

💡 Для Calendar Days:

Діапазон дат для призу має становити рівно один день. Наприклад: Start Date: 10.10.2024, End Date: 10.10.2024. Система автоматично встановлює ці дати при створенні днів, але переконайтеся, що ви не змінюєте їх на більший діапазон.

🎨 Крок 4: Застосування скіна

  • У налаштуваннях гри знайдіть поле «Skin».
  • Оберіть створений раніше скін зі списку (як створити скін — див. Розділ 4).

🔐 Крок 5: Налаштування доступу та видимості

  • Видимість Who can see the game: оберіть відповідний сегмент.
  • Налаштуйте кондиції Trigger, як гравець потрапляє в гру (посилання в email, API, manual grant).
  • Game UI configuration: тут можна налаштувати вигляд та поведінку інтерфейсу в CSS.

🧪 Крок 6: Тестування

  • Створіть тестовий сегмент з 2-5 email-адресами.
  • Надішліть тестове посилання та перевірте:
    • Коректність відображення на десктопі та мобільному.
    • Часовий пояс (midnight reset).
    • Стани призів (locked / active / claimed).
    • Fallback при закінченні призів.

🚀 Крок 7: Запуск

  • Переключіть гру в статус «Active».
  • Заплануйте email-кампанію з посиланням на гру.

💡 Як отримати та використовувати посилання на Lootbox (Deep link)

Для запуску Lootbox використовуються діплінки (deep links). Після створення гри автоматично створюється Custom Section з такою ж назвою. Вам потрібен ID цього Custom Section. Знайти його можна:

  • У списку Gamification → Custom Sections.
  • Або в налаштуваннях гри (після збереження з'являється поле "Custom Section ID").

Базовий формат посилання: dp:gf_section&id=XXX, де XXX — ID Custom Section.

Рекомендований формат для Email (standalone): dp:gf_section&id=XXX&standalone=true — відкриває гру як окремий елемент без лівого меню та верхнього колонтитула.

🏆 3. Кейси налаштування: CARDS та MAP

🃏 Кейс 1: Щоденні бонуси на будні (Layout: CARDS, Weekdays)

Мета: Підтримувати щоденну активність у будні (понеділок-п'ятниця) з простими призами. Цей підхід ідеальний для старту, оскільки не потребує складної кастомізації позицій.

Покрокове налаштування:

  1. Створіть гру з типом Lootbox 2.0, Layout Cards.
  2. Schedule: Weekdays.
  3. Оберіть дні: Mon, Tue, Wed, Thu, Fri.
  4. Recurrence: weekly (повторюється щотижня).
  5. Timezone: оберіть Calendar days, user time zone, щоб кожен гравець мав можливість відкрити картку до півночі за своїм часом.
  6. Завантажте скін для Cards (або використайте готовий). Для Cards обов'язкові файли: game-bg (JPEG, до 900kb) та game-bg-mobile (JPEG, до 900kb). На відміну від Map, тут немає обмежень щодо кількості днів.
  7. Налаштуйте призи для 5 днів (по одному на день).
  8. Встановіть Attempts per day: 1.
  9. Отримайте deep link (див. розділ 2, крок 7).

🗺️ Кейс 2: Адвент-календар (Layout: MAP, Calendar Days)

Мета: Провести 25-денну новорічну акцію (або будь-яку іншу подієву акцію) з різними призами кожного дня. Цей варіант більш видовищний, але потребує ретельної підготовки скіна.

Покрокове налаштування:

  1. Створіть гру з типом Lootbox 2.0, Layout Map.
  2. Schedule: Calendar Days.
  3. Start Date: 01.12.2026, End Date: 25.12.2026. Важливо: Максимальна кількість днів для Map — 31. Офіційно підтримувані кількості для автоматичного позиціонування: 7, 14, 25, 31 день. Для 25 днів система автоматично розставить призи.
  4. Timezone: Calendar days, user time zone (щоб приз активувався опівночі за часом гравця).
  5. Завантажте скін для 25 днів (розміри: game-bg = 1835x3895 px, game-bg-mobile = 527x3260 px, обидва JPEG <900kb).
  6. Налаштуйте призи для кожного з 25 днів. Система автоматично створила 25 днів після вибору дат.
  7. Для великих призів налаштуйте Prize Acknowledgment (див. розділ 2).
  8. Якщо ви хочете провести акцію на нестандартну кількість днів (наприклад, 10 днів), оберіть найближчий більший шаблон (14 днів) і скоригуйте позиції через CSS (див. розділ 4).

🎨 4. Кастомізація скінів — покрокова інструкція

📍 Де знаходиться редактор скінів?

Перейдіть у Back Office → Gamification → Mini-games skin.

💡 Готовий скін 'Sweet Choco'

Для макету Map в системі вже доступний готовий універсальний (не сезонний) скін 'Sweet Choco'. Ви можете використовувати його "з коробки" без залучення дизайнерів!

📝 Покрокова інструкція створення скіна:

КрокДія
1Натисніть кнопку «Create New Skin»
2У полі «Mini-game type» оберіть Lootbox
3Введіть «Name» — назву вашого скіна
4Оберіть «Layout» — Cards або Map
5Натисніть «Upload package» та завантажте підготовлені файли (кожен файл окремо, не ZIP-архівом)
6(Опціонально) Додайте «Custom CSS» для змін шрифтів або позицій (див. нижче)
7Натисніть «Save»

⚠️ Важливі вимоги при завантаженні:

  • Фонові зображення (game-bg, game-bg-mobile) ОБОВ'ЯЗКОВО мають бути у форматі JPEG та вагою до 900 KB. Це стосується як Map, так і Cards.
  • Назви файлів мають ЗБІГАТИСЯ з назвами в референс-пакеті.
  • Зображення потрібно завантажувати розархівованими (кожен файл окремо).

💡 Перевірка завантаженого пакета

Після завантаження система покаже детальну інформацію про кожен файл: попередній перегляд, формат, розміри, статус, вагу. Якщо є відсутні або неправильні файли — ви отримаєте сповіщення одразу.

🎯 Налаштування позицій через CSS (для макету MAP)

При використанні макету Map на 25 або 31 день позиції деяких призів можуть потребувати ручного коригування. Особливо це актуально, якщо ви використовуєте шаблон на 14 днів для 10-денної акції. У полі «Custom CSS» додайте:

/* Для десктопу */
.desktop-week-prize-1 {
    top: XXXpx !important;
    left: YYYpx !important;
}
.desktop-week-prize-2 { ... }
/* Для мобільних пристроїв */
.mobile-week-prize-1 {
    top: XXXpx !important;
    left: YYYpx !important;
}

Правило: При зміні CSS обов'язково використовуйте !important. Номери класів відповідають дням (1,2,3... максимум 31).

💡 Додаткові CSS-класи

Ви також можете налаштовувати позиції для кнопок, фону та інших елементів. Детальніше дивіться в документації Smartico.

🖌️ 5. ТЗ для дизайнерів — всі файли, формати та розміри

⚠️ Важливо: Нові поп-апи (Updated Pop-ups)

Для всіх новостворених скінів опція 'Use new pop-ups' увімкнена за замовчуванням і не може бути вимкнена. Це означає, що ви обов'язково повинні завантажити пакет зображень, який містить файли для нових поп-апів (див. таблиці нижче). Колір шрифту текстового контенту в поп-апах можна налаштувати за допомогою поля 'Override CSS'.

⚠️ Увага на розміри картинок

В таблицях нижче наведені розміри картинок які відповідають стандартам, але ті розмірои біля яких вказаний знак "~" (приблизні значення) це означає, що потрібно витримати пропорції, а розмір в пікселях може бути довільним. Наприклад, якщо вказано ~568×874px, то картинка може бути 568×874, 1136×1748, 284×437 і т.д., але пропорції повинні залишатися однаковими.

❓ 6. Часті питання (FAQ)

❓ Чи можна зробити лутбокс на 3, 10 або 20 днів?

⚠️ Відповідь згідно з технічною документацією

Офіційно підтримувані варіанти для макету MAP: 7, 14, 25, 31 день. Саме під ці варіанти в документації вказані точні розміри фонових зображень, і для них система автоматично розставляє призи по правильних позиціях.

Максимальна кількість днів для MAP: 31 день. Більше днів додати неможливо.

Рішення для нестандартної кількості днів (наприклад, 10 днів):

  • Варіант 1 (Макет Cards): Використовуйте макет CARDS — він має фіксований фон і не має жорсткої сітки позицій, тому автоматично адаптується під будь-яку кількість днів. Це рекомендований спосіб для початкового етапу.
  • Варіант 2 (Кастомізація макету Map): Оберіть найближчий більший макет (наприклад, 14 днів для 10-денної акції). У редакторі скінів у полі Custom CSS ви можете вручну змінити позиції призів за допомогою класів .desktop-week-prize-X та .mobile-week-prize-X. Важливо: при зміні позицій через CSS обов'язково використовуйте правило !important.

❓ Чому не завантажується пакет зображень?

  • Перевірте, чи фонові зображення game-bg та game-bg-mobile збережені у форматі JPEG (не PNG).
  • Перевірте, чи назви файлів точно відповідають специфікації (чутливі до регістру).
  • Переконайтеся, що ви завантажуєте файли окремо, а не ZIP-архівом.
  • Перевірте вагу фонових зображень — має бути менше 900 KB.
